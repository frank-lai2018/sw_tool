# SnapDesk

繁體中文 Windows 截圖、圖片編輯與螢幕錄影工具，以 PicPick 的主要使用流程為功能參考，使用獨立的程式與介面。目前版本為 0.1.9，尚未達到 PicPick 的完整功能範圍。

## 開啟

雙擊工作區根目錄的 `SnapDesk-0.1.9-Windows-x64.exe` 即可啟動。更新時請先關閉舊版，再開啟新版，以便新版註冊截圖快捷鍵。這是 Windows x64 自包含單檔版本，不需另外安裝 .NET。目標為 Windows 10／11 x64；本機已完成建置與介面驗證，尚未在乾淨的其他電腦驗證。錄影引擎另需 Microsoft Visual C++ 2015–2022 x64 執行階段，Windows N／KN 需有 Media Feature Pack；缺少元件時會顯示載入錯誤，請使用[微軟官方安裝程式](https://aka.ms/vs/17/release/vc_redist.x64.exe)。

## 編輯功能區

0.1.5 使用分組功能區：剪貼簿、影像、工具、大小、色彩與調色盤。大圖示可選繪圖、箭頭、裁切、螢光筆、文字、編號、馬賽克與取色；「圖形」選單提供矩形、橢圓、直線。「旋轉」選單提供旋轉與翻轉，「特效」提供馬賽克與螢光標示工具。點選色盤或「更多」選擇繪圖色彩。較窄視窗可在功能區底部水平捲動。

## 操作

- `Ctrl+Shift+1`：全螢幕截圖（所有螢幕）。
- `Ctrl+Shift+2`：範圍截圖。
- `Ctrl+Shift+3`：點選視窗截圖。
- `Esc`／滑鼠右鍵：取消截圖或離開螢幕工具。
- `Ctrl+O` 開啟、`Ctrl+N` 白色畫布、`Ctrl+V` 貼上。
- `Ctrl+S` 儲存、`Ctrl+Shift+S` 另存、`Ctrl+C` 複製整張圖片。
- `Ctrl+Z` 復原、`Ctrl+Y` 重做、`Ctrl+W` 關閉圖片。

截圖後會開啟新分頁。點選上方的標註工具，在圖片上拖曳繪製。文字、編號與圖片取色工具使用單擊。裁切工具拖曳框出要保留的範圍，放開滑鼠即套用；可以復原。星號表示圖片有尚未儲存的內容。

### 再次編輯圖形與文字（0.1.6）

- 圖形畫完會自動選取，顯示藍色選取框與控制點。選「移動」工具可重新點選既有物件，拖曳移動，拉邊緣或角落控制點改大小；直線與箭頭可拖曳兩個端點調整長度與方向。
- 選取物件後，色盤與「筆畫寬度」會套用到該物件。工具列會顯示選取物件目前的色彩與粗細，不會修改其他截圖的標註。
- 文字可以雙擊、按 `F2`，或使用圖片右鍵選單的「編輯文字」修改內容。可用「文字大小」、色盤與「粗體」修改字級、顏色、字重；也可用控制點縮放文字框。
- `Delete` 刪除選取物件，`Esc` 取消選取或正在進行的拖曳。新增、移動、縮放、文字內容與樣式修改均支援 `Ctrl+Z`／`Ctrl+Y`。
- 圖片旋轉、翻轉、調整大小與裁切後，標註仍可編輯；馬賽克區域也可重新選取、移動、縮放或刪除。
- 複製、列印、PNG／JPEG／BMP 匯出會合成背景與全部標註，不包含選取框或控制點。儲存後，在目前仍開啟的分頁中可以繼續編輯。

可編輯物件目前保存在開啟的分頁中；關閉後重新開啟 PNG／JPEG／BMP，或載入舊版已合成的圖片時，標註已是一般像素，無法還原成獨立物件。目前尚未提供可保存物件的專案檔格式。

### 圖形面板、曲線與雙色設定（0.1.7）

按「圖形 ▾」開啟圖示面板，可選矩形、正方形、圓角矩形、橢圓、圓形、三角形、菱形、五至八邊形、五／六／八／十二角星、愛心、對話框、四方向箭頭和雙向箭頭。正方形與圓形初次繪製會限制寬高相同，之後仍可自由縮放。

「直線／曲線」區提供直線、箭頭直線、控制點曲線與自由曲線。控制點曲線拖曳建立後，點選可用四個控制點改變彎曲程度；自由曲線依滑鼠拖曳軌跡建立，之後可移動與縮放。

按色彩區的「外框色」或「填滿色」方塊，切換色盤目前修改的目標；再點色盤選色。藍色邊框表示目前色盤目標。外框與填滿的顏色獨立保存，選取既有圖形後可直接修改。

- 「外框 ▾」可選自訂色、實線、虛線與無外框。
- 「填滿 ▾」可選自訂色、使用填滿與無填滿。
- 關閉外框時會保留填滿；關閉填滿時會保留外框，避免產生完全無法看見的物件。
- 封閉圖形才使用填滿；文字顏色沿用外框色，線條使用外框色與粗細。

先選取一個封閉圖形，再開啟圖形面板，按「＋ 將選取圖形加入自訂」，輸入名稱即可保存。自訂項目保存形狀與方向，繪製時套用當前外框、填滿及粗細；保存於 `%LOCALAPPDATA%\SnapDesk\custom-shapes.json`，重開程式仍可使用，最多保留最近 40 個項目。

每個圖片分頁右側都有「×」，點一下可關閉該圖片。**在上方分頁標籤按右鍵**，可選擇「關閉這張截圖」、「全部關閉」、「關閉左邊所有截圖」或「關閉右邊所有截圖」。左右以按右鍵的那個分頁為基準，不包含它本身；「開始」分頁會保留。沒有可關閉的左／右分頁時，相應選項會停用。未儲存的圖片會先詢問是否儲存；批次關閉會先完成所有儲存確認，按取消或存檔失敗時不會關閉這一批圖片。關閉分頁不會刪除已存檔的圖片。

0.1.3 修正分頁列滑鼠移動時反覆重畫整區造成的閃爍：僅在進出關閉按鈕時更新按鈕區域，並對分頁及內容使用合成繪製緩衝。

**在截圖或圖片上按滑鼠右鍵，會先開啟選單；選擇「複製圖片」才會將整張圖片放入剪貼簿。** 切換到其他程式按 `Ctrl+V` 即可貼上，不需要先存檔。圖片周圍的灰色檢視區也提供相同選單，另有「另存圖片」與「復原」。複製包含目前已完成的標註，使用原始圖片解析度，不受顯示縮放比例影響。狀態列會顯示複製完成提示。

固定大小範圍以點選位置為左上角，超出整個桌面的部分會裁掉。任意形狀的外部保留透明，請儲存為 PNG；JPEG 與 BMP 會將透明處填白。

取色器會複製 `#RRGGBB` 至剪貼簿。像素尺拖曳矩形量測寬高與對角線。量角器依序點選起點、頂點、終點。白板可用 `Ctrl+Z` 復原與 `Delete` 清除。螢幕工具目前操作的是啟動時凍結的桌面影像；白板離開後不保存，若需保存筆跡請使用圖片編輯器。

## 捲動長截圖

1. 先開啟目標程式，將內容捲至要擷取的起點。
2. 選「捲動長截圖」，設定最多捲動次數，再框選內容內部，避開固定頁首、工具列及捲軸。預設由原本 20 次提高為 **200 次**，可設定 **20～1,000 次**，設定會保存。
3. 程式將滑鼠移入選取區域並向下捲動，每次等待 650 毫秒。頁面延遲更新或第一次比對不成功時，會在同一捲動位置最多再等候 3 次，每次 350 毫秒。
4. 進度視窗顯示已擷取段數、目前圖片高度與捲動次數。按「停止並保留」或按住 `Esc` 可中止，保留已完成的內容；結果會在編輯器開啟。進度視窗會排除於擷取之外；不支援排除時隱藏進度視窗，改用 `Esc` 停止。

0.1.9 只保留每次新增的影像列，避免長時間擷取時把所有重複畫面留在記憶體；比對改為直接讀取影像像素緩衝，減少大量逐點讀取。圖片上限為 **8,000 萬像素或 100,000 像素高**，任一先達到就停止並保留結果。例如 1,920 像素寬時，最多約 41,666 像素高。非常長的圖片會限制最大顯示倍率，讓整張圖片仍能透過捲動檢視；匯出保留原始解析度。

這是透過螢幕像素比對的實驗性功能。動畫、影片、懶載入、重複圖樣、固定元素、特殊捲動控制項或未支援滑鼠滾輪的程式，可能無法拼接或提前停止。無法確認重疊時會停止，狀態列會顯示結果。僅截到一個畫面時不代表已完成整頁。擷取後目標頁面會留在捲動後的位置；請檢查接縫與內容完整性。

## 螢幕錄影（0.1.8）

1. 按上方「● 錄影」、選單「錄影」，或通知區選單「螢幕錄影」。
2. 選「指定螢幕全螢幕」，再選要錄製的螢幕；或選「選取範圍」後拖曳框選內容。目前範圍必須完整位於同一個螢幕內。
3. 選擇 15／30／60 FPS、是否顯示游標，以及不倒數／3 秒／5 秒倒數。
4. 按需要勾選「錄製系統聲音」與「錄製麥克風」，可同時錄製；兩者預設關閉，使用 Windows 預設裝置。無可用裝置時選項會停用，接上後按「偵測聲音裝置」更新。麥克風須允許桌面應用程式存取。
5. 確認 MP4 儲存位置，按「開始錄影」。預設存至「影片\SnapDesk」。編輯器會隱藏，控制列會縮成小視窗。
6. 使用「暫停／繼續」與「停止並儲存」按鈕，或 `Ctrl+Shift+F9`／`Ctrl+Shift+F10`。也可用通知區錄影圖示的選單控制。暫停時間不計入影片。
7. 停止後會完成 MP4，並提供「播放影片」與「開啟資料夾」。錄影中的控制列按「×」會先停止並儲存，再關閉；倒數時按「×」會取消。

使用 H.264 MP4 與可選的 AAC 聲音。H.264 輸出會將奇數寬高的右側／底部最多裁掉 1 像素。影片先寫入儲存目錄的暫存檔，完成後才移到指定檔名；若已有同名影片會先詢問是否取代。若失敗，非空的暫存影片會保留，錯誤訊息會告知位置。

Windows 10 2004 以上會將錄影控制列排除於擷取之外；不支援或設定失敗時隱藏控制列，改用快捷鍵或通知區停止。快捷鍵被占用時會顯示提示。不支援排除控制列且停止快捷鍵也不可用時，會拒絕開始，以免無法停止。可錄內容仍受顯示卡、受保護畫面與 Windows 安全桌面限制。目前未提供攝影機疊圖、影片剪輯、多螢幕同時錄影或錄影途中切換錄製範圍。

引擎採用 [ScreenRecorderLib 7.0.1](https://github.com/sskodje/ScreenRecorderLib)，MIT 授權文字位於 `ThirdParty/ScreenRecorderLib.LICENSE.txt`，亦內嵌於執行檔。採用 Windows Media Foundation 編碼，FFmpeg 僅用於開發驗證，不是執行依賴。初次啟動單檔版本時會解壓所需程式元件至 Windows 暫存目錄。

## 設定與限制

設定保存在 `%LOCALAPPDATA%\SnapDesk\settings.json`。自動儲存預設關閉，開啟後預設存至「圖片\SnapDesk」，可自行選資料夾。快捷鍵固定為上述三組；如被其他程式占用，狀態列會提示，仍可透過按鈕或通知區選單截圖。請只開啟一個 SnapDesk 實例。

圖片上限原則為 8,000 萬像素；復原最多保留 24 個步驟，並依 192 MiB 歷史影像預算刪除較舊步驟。大型圖片仍可能使用較多記憶體。受保護的影片、系統安全桌面及遮蔽內容不保證可擷取。視窗截圖擷取當前可見畫面，不會還原被其他視窗遮住的內容。

尚未提供：視窗內控制項截圖、靜態截圖游標疊加、雲端／FTP 上傳、OCR、自訂全域快捷鍵、完整圖層管理與可保存物件的專案格式、陰影／邊框等完整效果、PicPick 的完整調色盤與分享功能。實際多螢幕不同縮放比例、第三方程式長截圖與印表機相容性仍需要更多測試。

## 開發與驗證

需要 .NET 10 SDK 與 Windows。

```powershell
dotnet build .\SnapDesk\SnapDesk.csproj -c Release
.\SnapDesk\build.ps1
```

`build.ps1` 會發佈自包含單檔版本、執行內建檢查，成功後複製到工作區根目錄。也可執行 `SnapDesk.exe --self-test`，結果寫入執行檔旁的 `test-results.txt`；失敗會傳回非零結束碼。

執行 `SnapDesk.exe --recording-test` 會顯示程式產生的測試畫面，進行短片錄製、暫停／繼續、停止，以及錄影控制介面儲存測試。結果寫至執行檔旁的 `recording-test-results.txt` 與測試 MP4；測試不錄製系統聲音與麥克風。可另用 FFprobe／FFmpeg 檢查影片編碼、尺寸、長度與控制列排除效果。實際聲音裝置錄製仍需在有對應裝置的電腦測試。

測試包括反向選取、封閉任意形狀的外框、旋轉與尺寸變更的復原／重做、馬賽克邊界、輸出解碼與透明處理、覆寫存檔、捲動位移辨識與拼接、量角器，以及分頁關閉按鈕、左右批次關閉、取消／儲存失敗時保留分頁與圖片資源釋放。自動測試不代表已在所有第三方程式或不同 DPI 螢幕組合完成實測。
