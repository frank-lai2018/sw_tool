# MD Reader 使用說明

適用版本：Windows 免安裝版 1.3.1，含目錄拖曳調整、檔案右鍵開啟、多視窗、頁寬調整及大型文件分頁功能。
更新日期：2026 年 10 月 26 日。

MD Reader 是一個繁體中文介面的 Markdown 檔案閱讀器，可以將 `.md` 文件顯示成有標題、清單、表格和程式碼排版的頁面。文件在本機讀取，閱讀功能不需要帳號或網路。

> 最快開始方式：將 `MD-Reader-1.3.1-Windows.exe` 複製到電腦，雙擊執行，再把 `.md` 檔案拖進視窗。

## 一、新電腦如何安裝與準備

### 1. 確認電腦環境

本版提供 **Windows 10 / Windows 11 的 64 位元（x64）執行檔**。可從 Windows「設定」的系統資訊頁面確認電腦的系統類型。

- 不需要安裝 Node.js、Python、Electron 或其他開發工具。
- 不需要先安裝本專案的原始碼或套件。
- 程式執行時會使用使用者的暫存資料夾與設定資料夾，請保留足夠磁碟空間，並確認這些位置可正常寫入。

### 2. 把程式複製到新電腦

在原電腦的 `F:\md_sw\dist` 資料夾內，找到以下兩個檔案：

```text
MD-Reader-1.3.1-Windows.exe
使用說明.md
```

使用隨身碟、區域網路或其他檔案傳輸方式，將這兩個檔案複製到新電腦。新電腦不需要有 F 槽，也不必使用原本的資料夾名稱。

建議建立一個固定的資料夾，例如：

```text
C:\Users\你的使用者名稱\Documents\MD Reader\
├─ MD-Reader-1.3.1-Windows.exe
└─ 使用說明.md
```

**免安裝版只需要這個 EXE 即可執行。** `使用說明.md` 是供你閱讀的手冊；不用複製 `node_modules`、`src`、`win-unpacked` 或整個開發專案。

若你收到的是壓縮檔，請先解壓縮到一般資料夾，再執行裡面的 EXE。

### 3. 第一次啟動

1. 雙擊 `MD-Reader-1.3.1-Windows.exe`。
2. 等待程式完成暫時解壓縮並顯示閱讀視窗；首次啟動可能需要稍等一下，請避免連續重複點擊。
3. 全新使用時會先看到歡迎範例。若這台電腦已經使用過，程式會嘗試開啟上次閱讀的文件。
4. 點「開啟文件」，選擇這份 `使用說明.md`，即可用閱讀器查看手冊。

這個版本沒有一般安裝精靈，執行 EXE 就能使用，通常不需要系統管理員權限。

執行檔尚未進行數位簽章，因此 Windows 可能顯示來源或信譽提示。請先確認檔案來自你信任的來源；若是公司電腦受到管理政策限制，請交由管理人員確認，不要停用防護軟體。

### 4. 建立方便開啟的入口

可在檔案總管對 EXE 建立捷徑，再將捷徑放到桌面。保留 EXE 在原本的固定資料夾，避免之後移動檔案導致捷徑失效。

### 5. 加入檔案右鍵選單與開啟方式

在新電腦上只需設定一次：

1. 先將 EXE 放到固定資料夾，再開啟 MD Reader。
2. 按 `Alt` 顯示上方選單。
3. 選擇「Windows 整合」→「加入檔案右鍵選單」。
4. 看到完成提示後，回到檔案總管，對 `.md` 檔按右鍵。
5. 選擇「使用 MD Reader 開啟」，文件會在閱讀器中開啟；也可在「開啟方式」中選擇 MD Reader，若未直接列出，請展開其他應用程式清單。

Windows 11 的簡化右鍵選單可能需要先點「顯示更多選項」，才看得到「使用 MD Reader 開啟」。參見 [Microsoft 的檔案總管說明](https://support.microsoft.com/en-gb/windows/experience/fileexplorer/file-explorer-in-windows?nochrome=true)。

設定適用目前的 Windows 使用者帳號，支援 `.md`、`.markdown`、`.mdown`、`.mkd`。它會新增可選的開啟方式，不會直接改變原本雙擊文件時使用的預設程式。

右鍵選單登錄的是 EXE 的固定完整路徑。**搬移、重新命名 EXE 或改用新版 EXE 後，請在新位置執行程式，再操作一次「加入檔案右鍵選單」以更新路徑。** 換到另一台電腦或另一個 Windows 帳號，也需要重新設定。

如要取消整合，開啟閱讀器，選擇「Windows 整合」→「移除檔案右鍵選單」。若公司管理政策阻擋這項設定，請由管理人員確認。

若只想用原本方式閱讀，不需要登錄右鍵選單；仍可先開啟閱讀器，再拖入文件或按 `Ctrl + O`。

## 二、如何開啟 Markdown 文件

有三種基本方式，擇一使用即可：

| 方式 | 操作 |
| --- | --- |
| 點選按鈕 | 點左側「開啟文件」，選取文件後開啟。 |
| 使用快捷鍵 | 按 `Ctrl + O`，選取文件後開啟。 |
| 拖曳檔案 | 從檔案總管將文件拖進閱讀器視窗，放開滑鼠。 |
| 檔案右鍵 | 完成 Windows 整合設定後，對文件按右鍵，選擇「使用 MD Reader 開啟」。 |

支援的副檔名：`.md`、`.markdown`、`.mdown`、`.mkd`、`.txt`。單份文件上限為 **100 MiB**。

一次拖入多個檔案時，只會開啟其中第一個檔案。開啟另一份文件會切換目前顯示的內容。

### 同時開啟多個視窗

可同時使用多個獨立閱讀視窗，方便對照不同文件：

- 點左側「新視窗」，或按 `Ctrl + N`，即可再開一個視窗。
- 也可以再次雙擊 EXE，啟動另一個閱讀器視窗。
- 在每個視窗分別使用「開啟文件」或拖曳檔案，選擇要閱讀的文件。
- 每個視窗的文件、目錄、搜尋及捲動位置各自獨立；關閉其中一個視窗，其他視窗仍可繼續使用。
- 新視窗會嘗試顯示最近開啟的文件，再開啟另一份文件即可並排閱讀。

主題、字體與頁寬仍會保存為下次開啟使用的偏好。更新程式前，請先關閉所有舊版視窗。

### 最近開啟的文件

點左側「最近開啟」，可以查看最近讀過的文件，點選名稱就能再次開啟。最多保留 12 筆紀錄。

最近開啟清單儲存的是文件路徑，不是文件副本。文件被移動、重新命名或刪除後，需要重新選取正確的檔案。

## 三、閱讀畫面與功能

### 文件目錄

左側「文件目錄」會依文件中的標題自動產生章節清單。點選章節即可跳到該處。

如果目錄是空的，通常是文件沒有使用 Markdown 標題，例如 `# 大標題` 或 `## 章節標題`。

左上角的側邊欄圖示可以隱藏或顯示左側欄，讓閱讀區有更多空間。

### 拖曳調整左側目錄寬度

1. 將滑鼠移到左側目錄與右側閱讀區之間的垂直分隔線，游標會變成左右調整形狀。
2. 按住滑鼠左鍵向右拖曳，目錄會變寬，方便閱讀較長的章節名稱；向左拖曳則會縮窄目錄。
3. 放開滑鼠後會自動保存，重新開啟仍會沿用。
4. 雙擊分隔線，可恢復預設的 248 px 寬度。

目錄寬度範圍為 200–600 px。視窗較窄時會自動限制目錄寬度，保留閱讀空間；將視窗放大後會恢復原本設定的寬度。拖曳不會重新載入文件。

也可用 Tab 將焦點移到分隔線後，使用左右方向鍵調整；按住 Shift 可加大調整幅度，Home／End 分別調到目前可用的最小／最大寬度。

### 大型文件分頁閱讀

大型文件會自動切換為分頁閱讀，只建立目前頁面的內容，以降低大型表格的記憶體用量。頁數是閱讀器的內容分段，不代表實際列印紙張數。

- 使用閱讀區上方的「上一頁」、「下一頁」，或輸入頁碼並按 Enter 跳頁。
- 目錄仍包含整份文件的章節，點選後會自動切換到對應頁面。
- 搜尋仍會搜尋整份文件，使用 Enter／Shift+Enter 可在不同頁面的搜尋結果間跳轉。
- 跨頁表格會重複顯示欄位標題；表格資料列不會因為分頁而省略。
- 原始碼模式也會分頁，並在離開原始碼模式後釋放顯示內容。原始碼頁數與閱讀頁數可能不同。
- 特別長的程式碼不進行語法高亮；單一超長的 HTML、清單或文字區塊可能改以純文字分段呈現，以控制記憶體用量。

切換頁面會取代上一頁的畫面內容，原始 `.md` 檔案不會被修改。一般小文件仍以完整連續頁面呈現。

### 調整頁面寬度

閱讀區上方有「頁寬」滑桿：

1. 向左拖曳，頁面變窄；向右拖曳，頁面變寬。
2. 可設定的頁面最大寬度為 **600–1600 px**，每次調整 20 px；預設為 860 px。
3. 點「滿版」，頁面會填滿閱讀區的可用寬度，仍保留基本邊距。
4. 再點一次「滿版」，會回到目前滑桿的設定。

固定寬度會置中顯示。當視窗較窄時，實際頁寬會自動縮小以容納視窗；因此設定成 1600 px，也不會強迫小視窗變成 1600 px。

頁寬設定會自動保存，重新啟動後仍會沿用。閱讀模式與原始碼模式使用相同的頁寬設定。頁寬控制位於文件最上方，向下閱讀後可捲回頂端調整。

### 調整字體大小

使用頁寬控制旁的 **A−** 與 **A＋**：

- **A−**：縮小字體。
- **A＋**：放大字體。
- 可調整 13–24 px，預設為 17 px；標題依比例顯示。

字體大小會自動保存。

### 切換深色與淺色

點右上角的月亮圖示，或按 `Ctrl + Shift + L`，即可切換主題。設定會自動保存。

### 搜尋文件內容

1. 按 `Ctrl + F`，或點右上角放大鏡圖示。
2. 輸入想找的文字，符合的內容會標示顏色。
3. 搜尋框旁的數字表示「目前第幾筆 / 總筆數」。
4. 按 `Enter` 跳到下一筆，按 `Shift + Enter` 跳到上一筆，也可以點搜尋列的上下箭頭。
5. 按 `Esc` 或搜尋列的關閉按鈕，結束搜尋。

搜尋不區分英文大小寫，使用一般文字比對。閱讀模式會搜尋排版後的文字；切換原始碼模式後，會搜尋 Markdown 原始文字。單次最多標示 2,000 筆，超過時以 `2000+` 顯示。

### 查看及編輯原始碼

點右上角的 `</>` 圖示，可以切換閱讀模式與 Markdown 原始碼模式。

1. 開啟文件後，點右上角「編輯」修改整份 Markdown 原始碼。
2. 點「預覽」查看草稿的排版，或再點「編輯」繼續修改。
3. 點「儲存」或按 `Ctrl + S`，將草稿寫回原檔。切換文件、重新載入或關閉視窗時，程式會確認是否捨棄未儲存的變更。

儲存時保留原檔的 UTF-8 或 UTF-16 編碼。Big5 文件會先詢問是否轉為 UTF-8。如果磁碟上的原檔已有變更，請先複製草稿，再重新載入原檔，以便合併兩邊的修改。

### 重新載入修改後的文件

如果在其他程式修改並儲存了同一份文件，回到 MD Reader 後，按 `Ctrl + R` 或點右上角的重新載入圖示。

目前不會自動監看檔案變動，必須手動重新載入。歡迎範例不是磁碟上的文件，因此沒有重新載入的內容。

### 程式碼、表格與待辦清單

- 常用程式語言的程式碼區塊會顯示語法高亮。
- 程式碼區塊右上角的「複製」可將整段程式碼複製到剪貼簿。
- Markdown 表格會以表格呈現；較寬的表格或程式碼區塊可在區塊內水平捲動。
- 待辦清單會顯示勾選狀態，但不能在閱讀器中變更勾選內容。

### 列印或儲存為 PDF

1. 按 `Ctrl + P`，或點右上角印表機圖示。
2. 在列印視窗選擇印表機並調整列印設定。
3. 若要儲存 PDF，選擇 **Microsoft Print to PDF**，再指定檔名與儲存位置；這個選項須由 Windows 提供。

列印版面會隱藏側邊欄與工具列，使用白底並依紙張寬度排版。若目前顯示原始碼模式，列印的也是原始文字；要列印排版後的文件，請先切回閱讀模式。

**大型文件採分頁閱讀時，只列印目前顯示的閱讀頁或原始碼頁。** 程式會在開啟列印視窗前提示第幾頁及總頁數，避免一次展開整份文件導致記憶體大幅增加。本版未提供大型文件一次列印全文的功能。

## 四、圖片、連結與檔案搬移

### 本機圖片

圖片必須使用相對路徑，並放在 Markdown 文件所在資料夾或其子資料夾內。例如：

```text
我的筆記\
├─ 操作筆記.md
└─ images\
   └─ 畫面.png
```

在 `操作筆記.md` 中這樣引用：

```markdown
![操作畫面](images/畫面.png)
```

支援 PNG、JPEG、GIF、WebP、AVIF、BMP，單張圖片上限 **15 MB**。目前不支援 SVG 圖片，不會讀取文件資料夾以外的圖片路徑。

**把筆記搬到新電腦時，請連同圖片資料夾一起複製，並保留相同的資料夾結構。** 只複製 `.md` 檔案不會包含它所引用的圖片。

### 網路圖片與連結

- 網路圖片不會自動下載，會顯示未載入提示。
- 點選網頁連結，會使用 Windows 的預設瀏覽器開啟；瀏覽網頁仍可能需要網路。
- 點選相對路徑的 Markdown 文件連結，會在閱讀器內切換到另一份文件。
- 目前不支援數學公式排版與 Mermaid 圖表渲染。

### 中文編碼

程式會辨識 UTF-8、含 BOM 的 UTF-16；遇到不符合 UTF-8 的內容，會嘗試以 Big5 讀取。

若顯示亂碼，請使用文字編輯器確認原始編碼，再另存一份 UTF-8 文件後重新開啟。其他編碼未必能正確辨識，請保留原始檔案作為備份。

## 五、常用快捷鍵

| 快捷鍵 | 功能 |
| --- | --- |
| `Ctrl + O` | 開啟文件。 |
| `Ctrl + N` | 新增獨立閱讀視窗。 |
| `Ctrl + F` | 搜尋目前文件。 |
| `Enter` | 搜尋列中跳到下一筆。 |
| `Shift + Enter` | 搜尋列中跳到上一筆。 |
| `Esc` | 關閉搜尋。 |
| `Ctrl + R` | 重新載入目前文件。 |

也可按 `Alt` 顯示上方選單，再使用「檔案」、「編輯」與「檢視」中的功能。

## 六、更新、備份與移除

### 更新程式

1. 關閉所有 MD Reader 視窗。
2. 取得新版 EXE，放到你原本存放程式的資料夾。
3. 如果檔名相同，可用新版替換舊版；如果檔名不同，請一併更新桌面捷徑。
4. 啟動新版，確認功能正常後再整理舊版檔案。

目前沒有自動更新功能。在同一個 Windows 使用者帳號下使用相同應用程式身分的版本，會沿用原本的設定。

### 備份與換電腦

你可以備份三類資料：

| 資料 | 說明 |
| --- | --- |
| 程式與手冊 | EXE 與這份 `使用說明.md`。 |
| 你的文件 | `.md` 文件與其引用的圖片資料夾。 |
| 個人設定（選用） | 主題、字體、頁寬、目錄寬度及最近開啟紀錄。 |

個人設定一般儲存在 `%APPDATA%\md-reader\settings.json`。可按 `Win + R`，輸入 `%APPDATA%\md-reader` 後開啟資料夾。備份或還原設定前，請先關閉閱讀器。

新電腦即使不複製設定，也能正常使用，只需重新選擇主題、字體和頁寬。若複製了舊設定，最近開啟紀錄中的路徑可能已經改變，請重新開啟新位置的文件。

閱讀器不會備份或修改你的原始 Markdown 文件，請自行保管與備份文件。

### 移除程式

若曾加入右鍵選單，請先在閱讀器中選擇「Windows 整合」→「移除檔案右鍵選單」。再關閉閱讀器，刪除 EXE 及你建立的捷徑即可。若也要移除個人設定，可在確認已備份後，刪除上述設定資料夾。這不會刪除你另外存放的 Markdown 文件。

## 七、常見問題

| 問題 | 處理方式 |
| --- | --- |
| 新電腦需要安裝 Node.js 或其他套件嗎？ | 不需要，免安裝 EXE 已包含執行環境。 |
| 右鍵沒有「使用 MD Reader 開啟」？ | 先用 1.2.0 或更新版本執行「Windows 整合」→「加入檔案右鍵選單」；Windows 11 可再查看「顯示更多選項」。 |
| 右鍵選項存在，但無法啟動？ | EXE 可能已搬移或改名。開啟新位置的 EXE，再次執行加入右鍵選單，以更新登錄路徑。 |
| 開啟後暫時沒看到視窗？ | 首次啟動需要解壓縮，請稍候；若持續無法啟動，檢查磁碟空間、暫存資料夾權限及 Windows 顯示的提示。 |
| Windows 顯示來源提示？ | 本版未簽章。確認檔案來源；受管理電腦請由管理人員處理。 |
| 看不到「頁寬」滑桿？ | 先捲回文件頂端；如果仍看不到，關閉舊視窗，確認執行的是包含頁寬功能的新版 EXE。 |
| 頁寬設成 1600 px，卻沒有變那麼寬？ | 這是最大寬度。請放大視窗或隱藏側邊欄；小視窗會自動縮小頁面。 |
| 找不到先前開過的文件？ | 最近開啟只保留路徑。用「開啟文件」重新選取移動後的檔案。 |
| 雙擊大型文件後只看到歡迎範例？ | 1.3.0 舊版限制 20 MiB，失敗提示會自動消失。請使用 1.3.1 或更新版本，支援最大 100 MiB 並分頁閱讀；開檔失敗會持續顯示路徑與原因。更新後請重新加入 Windows 整合以更新 EXE 路徑。 |
| 圖片未載入？ | 確認圖片在文件資料夾內、相對路徑正確、格式受支援且未超過 15 MB；網路圖片不會自動載入。 |
| 在其他程式修改文件後，畫面沒有更新？ | 在該程式儲存，再回 MD Reader 按 `Ctrl + R`。 |
| 文字顯示亂碼？ | 確認文件編碼，另存一份 UTF-8 後重試。 |
| 文件目錄是空的？ | 確認文件有使用 `#`、`##` 等 Markdown 標題。 |
| 想要修改文字或勾選待辦項目？ | 點「編輯」修改 Markdown，將 `- [ ]` 改成 `- [x]` 可勾選待辦項目。 |
| 列印視窗沒有 PDF 選項？ | 確認 Windows 已提供 Microsoft Print to PDF，必要時請管理人員協助。 |

如果設定異常，可先關閉閱讀器，將 `settings.json` 改名為 `settings.backup.json`，再重新啟動。程式會使用預設設定；原始文件不受影響，備份的設定檔也會保留。
