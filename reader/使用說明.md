# 電子書閱讀器 使用說明

這是一個 Windows 上的電子書閱讀程式，可以閱讀 **EPUB、PDF、AZW3、AZW、MOBI** 格式的電子書（也能開 FB2、CBZ）。

---

## 一、安裝

### 系統需求

- Windows 10 或 Windows 11（64 位元）
- 不支援 Windows 7、Windows 8
- 不需要另外安裝其他軟體

### 選擇版本

| 檔案 | 適合 |
| --- | --- |
| `EbookReader-Setup-1.0.0.exe`（約 120 MB） | **建議使用**。安裝後有開始功能表捷徑，並可設定雙擊電子書檔案直接開啟 |
| `EbookReader-Portable-1.0.0.exe`（約 110 MB） | 免安裝。放在任何資料夾或隨身碟，雙擊即可執行，每次啟動會比安裝版慢幾秒 |

### 安裝步驟（安裝版）

1. 雙擊 `EbookReader-Setup-1.0.0.exe`。
2. 依照畫面指示安裝，可以自行選擇安裝位置。不需要系統管理員權限。
3. 安裝完成後，從開始功能表開啟「電子書閱讀器」。

### 出現「Windows 已保護您的電腦」怎麼辦？

第一次執行時，Windows 可能會跳出藍色的 SmartScreen 警告視窗，因為這個程式沒有購買數位簽章。

1. 點「**其他資訊**」。
2. 點「**仍要執行**」。

之後就不會再出現。

## 二、加入電子書

以下三種方式都可以：

- 點右上角「**開啟電子書**」按鈕，選擇檔案（可一次選多本）。
- 直接把電子書檔案**拖曳**到程式視窗裡。
- 安裝版設定好檔案關聯後，在檔案總管**雙擊**電子書檔案（設定方式見第五節）。

只選一本時會直接開始閱讀；一次加入多本時，會全部放進書架。

---

## 三、書架

開啟程式後看到的第一個畫面就是書架，會顯示每本書的封面、書名、作者和閱讀進度。

- **搜尋**：在右上角搜尋框輸入書名或作者。
- **排序**：可依「最近閱讀」、「最近加入」、「書名」、「作者」排列。
- **深色／淺色**：點右上角的月亮（或太陽）圖示切換。
- **右鍵選單**：在書上按右鍵，可以：
  - 在檔案總管中顯示檔案位置
  - 重設閱讀進度
  - 從書架移除（只是從清單移除，**不會刪除檔案**）

---

## 四、閱讀

點書架上的書就會開啟。程式會**自動記住閱讀位置**，下次開啟時從上次讀到的地方繼續。

### 翻頁

- 鍵盤左右方向鍵、PageUp／PageDown、空白鍵
- 滑鼠滾輪
- 點擊頁面左側或右側
- 拖曳底部的進度列，可快速跳到任意位置

### 上方工具列

| 按鈕 | 功能 |
| --- | --- |
| ← | 回到書架 |
| ☰ | 開關側邊欄（目錄、書籤、搜尋） |
| 🔍 | 在書中搜尋文字 |
| 🔖 | 在目前頁面加入或移除書籤 |
| T | 閱讀設定 |
| ⛶ | 全螢幕 |

### 側邊欄

- **目錄**：點章節名稱即可跳過去，目前所在章節會以顏色標示。
- **書籤**：列出所有書籤，點一下跳過去，點垃圾桶圖示刪除。
- **搜尋**：輸入文字後按 Enter，點搜尋結果即可跳到該處。

### 閱讀設定（工具列的 T 按鈕）

**一般電子書（EPUB、AZW3、MOBI 等）**

- **主題**：白、米黃、護眼綠、深色、純黑
- **字體大小**、**行距**
- **字型**：出版社預設、明體、黑體、楷體
- **版面**：分頁（像翻書）或捲動（像網頁）
- **欄數**：單欄，或視窗夠寬時自動顯示雙欄
- **版心寬度**、**頁邊距**、**左右對齊**

**PDF**

- **縮放**：符合頁面、符合寬度、75%～300%
- **雙頁並排**：視窗為橫向時一次顯示兩頁
- 選擇深色或純黑主題時，PDF 頁面會自動反轉為深色

### 全螢幕

按 F11 或工具列的全螢幕按鈕。全螢幕時工具列會自動隱藏，把滑鼠移到畫面最上方或最下方就會出現。按 Esc 離開全螢幕。

### 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| ← → | 上一頁／下一頁 |
| PageUp／PageDown、空白鍵 | 上一頁／下一頁 |
| Home／End | 跳到開頭／結尾 |
| Ctrl + 滑鼠滾輪 | 放大／縮小字體（PDF 為縮放） |
| Ctrl + =／Ctrl + − | 放大／縮小字體（PDF 為縮放） |
| Ctrl + 0 | 字體大小（PDF 縮放）恢復預設 |
| Ctrl + F | 搜尋 |
| Ctrl + D | 加入／移除書籤 |
| T | 開關目錄 |
| F11 | 全螢幕 |
| Ctrl + O | 開啟檔案 |
| Esc | 依序：關閉面板 → 離開全螢幕 → 關閉側邊欄 → 回到書架 |

## 五、讓電子書檔案雙擊就開啟（安裝版）

1. 在任一個 `.epub` 檔案上按右鍵。
2. 選「**開啟檔案**」→「**選擇其他應用程式**」。
3. 選「**電子書閱讀器**」，並勾選「**一律使用此應用程式開啟 .epub 檔案**」。
4. `.azw3`、`.azw`、`.mobi`、`.pdf` 如有需要，用同樣方式各設定一次。

PDF 若不設定，仍會用原本的程式（例如瀏覽器或 Adobe Reader）開啟。

## 六、換新電腦時搬移書架與閱讀進度

書架清單、閱讀進度、書籤和閱讀設定，都存在這個檔案：

```
%APPDATA%\電子書閱讀器\library.json
```

在檔案總管上方的網址列貼上 `%APPDATA%\電子書閱讀器`，按 Enter 即可打開這個資料夾。

### 搬移步驟

1. 在新電腦安裝程式，**開啟一次後關閉**，讓程式建立資料夾。
2. 把舊電腦的 `library.json` 複製到新電腦的同一個資料夾，覆蓋原本的檔案。
3. 把電子書檔案也複製到新電腦，而且**要放在和舊電腦完全相同的路徑**。
   例如舊電腦是 `D:\Books\紅樓夢.epub`，新電腦也要放在 `D:\Books\紅樓夢.epub`。

> **注意**：書架是用檔案的完整路徑來辨認每一本書。如果新電腦上的路徑不同，該書在書架上會顯示「找不到檔案」，需要重新加入，而那本書原本的閱讀進度與書籤無法保留。

## 七、常見問題

**Q：開啟時顯示「受 DRM 保護，無法開啟」？**
從 Kindle 商店、Google Play 圖書或其他使用 Adobe DRM 的書店購買的書通常有加密保護，本程式無法開啟。請改用該書店提供的官方閱讀軟體。

**Q：有些 Kindle 書打不開？**
新版 Kindle 的 KFX 格式不支援，只支援 AZW3、AZW、MOBI。

**Q：書架上的書顯示「找不到檔案」？**
檔案被移動、改名或刪除了。在書上按右鍵選「從書架移除」，再重新加入新位置的檔案。

**Q：PDF 搜尋後，頁面上沒有標出關鍵字？**
目前 PDF 搜尋只會跳到結果所在的頁面，不會在頁面上標記文字。EPUB 等其他格式會標記。

**Q：調整字體大小，有些書的字沒有變？**
少數電子書在檔案中寫死了字體大小，程式無法調整。可以改用「版心寬度」或主題設定讓閱讀更舒適。

**Q：PDF 可以改字型或字體大小嗎？**
不行。PDF 是固定版面，只能用「縮放」調整大小。

**Q：如何移除程式？**
- 安裝版：Windows「設定 → 應用程式」中找到「電子書閱讀器」，點「解除安裝」。
- 免安裝版：直接刪除 exe 檔即可。

無論哪一版，如果要連書架資料一起清除，請再刪除 `%APPDATA%\電子書閱讀器` 資料夾。電子書檔案本身不會被刪除。
